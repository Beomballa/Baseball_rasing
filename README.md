## 검증

Xcode의 Product → Test 또는 다음 명령으로 실행합니다. UI 테스트는 신규 선수 생성을 검증하므로 **전용 빈 시뮬레이터**를 사용합니다. 테스트 코드에는 사용자 세이브 초기화 기능이 없습니다.

V1→V2 경량 마이그레이션으로 달력 테이블만 추가합니다. 선수/구종 모델은 바꾸지 않으며 ID·학교·이름/번호·외형/손·능력치/숙련도·피로·저장 날짜를 유지합니다. 기존 선수는 그 저장 날짜를 나이 진행 기준일로 한 번 고정하고 기존 저장 표시를 붙입니다. 과거 경기 결과·행동 이력·프로 계약을 생성하지 않습니다. 신규/기존 선수 모두 달력을 명시 저장하며 재실행으로 조별리그가 재추첨되지 않습니다.

## 2026-10-19 일정 오류·부분 저장 안내 보강

- 일정 조회 성공/정상 비경기일과 실패를 구분한다. 날짜·6팀 대진·내 학교/선수 일치 오류는 원인과 ‘다시 확인’을 표시하고 휴식·다음 날·묶음 진행을 잠근다. 연간 일정에서도 같은 오류를 표시한다. 정상적인 졸업 후 빈 일정은 오류로 바꾸지 않는다. 진행 함수도 일정 유효성을 검사하므로 화면을 거치지 않는 호출로 행동을 소비하지 않는다.
- 묶음 진행 실패는 완료 일수/자동 휴식 횟수·마지막 저장일·피로 변화·중단 원인을 전달한다. 실패한 하루만 rollback하고 앞서 저장한 날은 보존한다. 현재 화면의 요약과 알림에 부분 성공을 표시하며 재실행 후에는 기존 날짜/피로 상태로 이어간다. 오류 안내를 위해 저장 스키마나 필드를 추가하지 않는다.
