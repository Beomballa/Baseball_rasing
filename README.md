<a id="overview"></a>
## 어떤 게임인가요?

16세 고교 선수로 시작해 직접 경기를 뛰고, 훈련과 경기 성적으로 성장하는 개인 커리어 게임입니다. 스카우트 관찰과 평가를 거쳐 국내·해외 진로와 계약으로 이어집니다.

**선수 생성 → 훈련·휴식 → 공식 경기 → 성장·기록 → 다음 일정**

| 항목 | 현재 기준 |
|---|---|
| 플랫폼 | iPhone · 세로 화면 · iOS 17 이상 |
| 조작 | 타자 스와이프 조준·탭 타격 / 투수 구종·코스 선택·릴리스 게이지 |
| 표현 | SwiftUI 정보 화면 + SpriteKit 도트 경기 연출 |
| 저장 | SwiftData 로컬 저장 · 서버·로그인·CloudKit 없음 |
| 개발 상태 | 기능 구현과 검증 진행 중 |

이 저장소는 iOS 네이티브 프로젝트입니다. 별도 웹 프로토타입과 전체 기획은 공개 소스 배포물에 포함하지 않습니다.

<a id="getting-started"></a>
## 실행하기

### 1. 프로젝트 열기

```sh
git clone https://github.com/Beomballa/Baseball_rasing.git
cd Baseball_rasing
open BM.xcodeproj
```

Xcode에서 공유 **BM** 스킴과 iPhone Simulator를 선택해 실행합니다. Swift 6 언어 모드, 최소 배포 타깃 iOS 17.0을 사용합니다. 최소 배포 타깃은 해당 OS에서의 검증 완료를 뜻하지 않습니다.

### 2. 실기기에서 실행하기

`Signing & Capabilities`에서 자신의 Team과 고유 Bundle Identifier를 설정합니다. 서명·프로비저닝·개인 Xcode 설정은 공유 소스에 포함하지 않습니다.

기존 선수가 있는 기기에서는 별도 QA 앱·저장 공간을 사용합니다. QA를 위해 기존 앱을 삭제하거나 사용자 저장을 초기화하지 않습니다.

### 일반 앱과 QA 앱 구분

| 실행 스킴 | 아이콘 | 앱 이름 | 용도 |
|---|---|---|---|
| BM · Debug/Release | 낮 구장의 타자 스윙 | 픽셀야구인생 | 일반 플레이 |
| BM-QA · QA | 노을 구장의 투수·금색 QA | BM 성능 QA | 별도 저장에서 검증 |

두 앱은 기존 Bundle ID로 함께 설치할 수 있습니다. QA에는 **BM-QA** 스킴을 사용합니다. Bundle ID만 바꾸면 QA 아이콘 구성이 적용되지 않습니다. 임시 저장·자동 진행 인수는 기존 QA 정책을 따릅니다.

### 3. 기본 플레이 흐름

1. 선수를 생성하고 능력치·구종·일정을 확인합니다.
2. 오늘의 훈련 또는 휴식을 선택합니다.
3. 경기일에는 오늘 경기를 시작하거나 이어서 진행합니다.
4. 경기 종료·결과 저장 후 홈에서 다음 날로 넘어갑니다.

미완료 경기는 날짜 진행을 잠급니다. 자유 연습은 실제 성장·기록·날짜·피로에 반영하지 않습니다.

### 저장할 때 지키는 원칙

- **SwiftData V15** — 기존 선수 ID·구종·원장을 이전하고 은퇴 선수를 보존합니다. 활성 선수는 역할별 1명으로 제한하며, 파일 이전 전에 DB 구성 파일을 별도 백업합니다.
- **명시 저장·실패 복구** — 자동 저장을 끄고 사건 단위로 저장합니다. 실패 시 오류·재시도를 제공하며 저장소를 자동 삭제하거나 임시 저장으로 전환하지 않습니다.
- **이어하기·1회 반영** — 경기·훈련의 진행 원장과 보상을 보존합니다. 다시 보기와 렌더링에서 새 판정·보상을 만들지 않습니다.
- **고정 근거** — 날짜·나이·피로·하루 행동, 28일 보고서·평가 창을 각 원장 규칙으로 관리합니다. 과거 미수집 기록을 추정해 채우지 않습니다.
