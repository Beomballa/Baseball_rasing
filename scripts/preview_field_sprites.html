수비 선수 · 원본 동작 검증

8방향 × 8동작. 기존 경기 캐릭터에 맞춘 원본 아트입니다. 실제 경기·저장과 연결되지 않는 별도 미리보기입니다.

불러오는 중
구장 폭에 맞춘 선수 크기와 원근을 적용합니다. 외야는 작게, 내야는 조금 크게 표시합니다. 대상을 선택하면 송구 → 공 비행 → 상대 포구 → 공 확보로 이어집니다. 실제 경기 판정과 무관한 동작 시연입니다.

선택 방향의 8동작

각 동작의 실제 불투명 경계를 사용합니다. 방향별 준비 자세의 키로 크기를 정하고, 포구 자세를 세로로 늘리지 않습니다. 파란 기준선은 발 위치입니다.
